# Proposed shorter pruning campaign

Status: proposal after the user-directed pause on 11 September 2026 at 16:04:03 UTC. No experiment in this plan has started, and no final recipe or next width cut is approved by this document. AdamW's completed recovery, Muon's paused process state and all earlier artifacts remain preserved. NorMuon and Shampoo are deferred, not discarded. The paused Muon process has 253 logged updates and a step-250 review; only its step-zero checkpoint exists on disk. There is no automatic resume.

1. **Profile protection first, and bring quiet diagnosis forward.** Use the saved matched evaluations to separate amplitude-only, residual-only and combined regressions across all seven quiet cohorts. This diagnosis is now a next priority, before changing the training rules. In a separately scoped replay, time the QP, Gram reductions and synchronization, anchor forward/reverse passes, normal corrections and transaction copies. Try only implementations preserving all twelve constraints, six anchors, thresholds and per-update nonlinear acceptance. Certified solver early exit, consolidated casts/reductions and verified duplicate elimination need actual accepted-update parity. Neither audit requires finishing the deferred optimizer trials first.

2. **Prepare two substantial width candidates with generic selection and reconstruction.** First target stage 2 / stage 3 at `256 / 256`, then `256 / 128` if the first cut is useful. These are 50% of the respective original widths, retaining all nine residual units and temporal support. Select channels on calibration data, identify every affected residual mixer and adjacent upsampler, and reconstruct from actual student features after each change. Preserve native phase geometry, shared bias, context and valid tails. Build each independent candidate from the fixed original teacher with a fresh optimizer, not a trained checkpoint. Requalify startup feasibility for the new geometry; the present four-site implementation is not automatically sufficient for both cuts.

3. **Make measured CPU gain a prerequisite for substantial recovery.** Compare each exported native candidate with the retained baseline on the same intended deployment CPU, precision, output/context contract and warmup. Primary measurements are one-thread streaming at 80 ms and 160 ms; report median and tail chunk latency, real-time factor and memory. Keep batch/whole-recording results separate. Propose a minimum 10% median latency improvement beyond observed variation, without material tail regression, as a screening gate fixed before measurement. It is a practical budget rule, not a universal threshold. Static convolution costs are 7.8674, 6.8614 and 5.1741 GMAC/s for `384 / 256`, `256 / 256` and `256 / 128`; they exclude activation, memory and dispatch work and are not speedup predictions.

4. **Use one fixed AdamW recipe and short recovery decisions.** Propose the existing AdamW `3e-5`, betas `0.9 / 0.99`, epsilon `1e-8`, zero weight decay as the reference, with no new optimizer or rate grid. Keep the teacher, ordinary objectives and matched source order fixed. Start with 64 updates to check feasibility and real learning, review at 250, and cap screening at 500 per candidate. Report six recurring calibration sources separately from ordinary unique sources; all 96 development sources and seven quiet cohorts remain evaluation only. Halt on invalid state, broken protected constraints or sustained negligible parameter movement. Review persistent waveform/quiet regression rather than automatically extending to improve a single metric. A longer fresh recovery is earned only by measured CPU benefit and useful short-run recovery, then explicitly scoped; no automatic long run or next cut.

5. **Keep cheaper training rules separate from implementation speedups.** Fewer anchors, intermittent checking, stale Jacobians or a quiet-loss penalty change what is protected. Consider such alternatives only after the saved quiet diagnosis, in a declared matched short comparison with the current rule. Preserve all original thresholds for evaluation and report calibration protection, held-out starts, broad quiet, ordinary reconstruction and wall time separately. Do not label a faster rule equivalent before validation, and do not infer a capacity limit from one failed short run.

The aim is to identify a useful speed/quality tradeoff with fewer long trials. No 10× speedup or near-perfect fidelity is promised. Correlation is not perceptual accuracy.
