The deployed structure

A width cut, with every residual unit retained

The current cut removes 128 of the original 512 stage-2 channels. Stage 3 remains at 256 channels and stage 4 at 128. Each of these three stages still contains three residual units. This is a 25% stage-2 width reduction, not removal of three layers or a quarter of the entire decoder.

RU = residual unit. Rates are internal temporal rates; samples per cell refer to the final 48 kHz waveform.

Channel removal changes what later operators receive. For this cut, the four reconstruction sites are the three stage-2 pointwise residual mixers and the stage-3 transposed-convolution upsampler. Their weights must be handled consistently with original channel identities, residual skips, conditioning, Snake activations, causal context and output trimming.

Inference stays native. Reconstruction maps are folded into existing weights. The startup constraints and correction solver run only while training. They do not add a decoder layer, teacher branch, projection head or inference-time solver.
Fresh construction, then calibration

Reconstruct the features the narrowed model actually produces

01 · Original teacher

Build a fresh narrowed copy

Use fixed original-coordinate support and original teacher weights. Do not install a trained compressed checkpoint or an old group's tensors.

02 · Native G fits

Fit, fold, recompute

Use 72 calibration sources. Fit each hidden reconstruction map, fold it into its native consumer, then recapture actual student inputs for the next fit.

03 · Startup refit

Refit the existing upsampler

Keep the three G residual mixers exact. Fit only stage 3's upsampler using changed G inputs and training-only startup constraints.

04 · Recovery

Train under physical checks

Start fresh Adam. Preserve the ordinary losses while projecting and, when necessary, correcting the native parameter update.

GRAIL-like native reconstruction

On the fixed channel support, fit an uncentered, zero-intercept ridge map R from current student features to teacher features. Fold that map into the corresponding consumer. A single map is shared across all ten upsampler taps, and the original biases are preserved during the G fits. The map is a calibration device, not an extra deployed operation.

hteacher ≈ R hstudent
Wnative,new = Wteacher,consumer R
After every fit, rerun the student to obtain the next site's actual inputs.

This adapts GRAIL's post-hoc linear reconstruction to these native audio operators. The published method is evidence for the construction idea, not proof of codec quality, startup preservation or this exact recovery procedure.

Constrain startup using the changed G inputs

The new initializer refits the stage-3 upsampler from G's own features. It does not transplant the earlier A or C upsampler. The native operator has 384 input channels, 256 output channels, stride 5, kernel 10, five output phases and one shared output bias. Its design includes current and previous input frames. Context is retained; a zero previous frame applies only at the true start of a source.

The ordinary native delta-ridge fit uses the same 72 calibration sources and the fixed regularization policy. Equality constraints use whole eight-sample feature cells within the six observed training-calibration near-startup windows. Selection follows the original cached teacher mask on the absolute source time grid. The teacher's complete upsampler output is the equality target.

minΔW, Δb weighted calibration error + fixed ridge penalty
subject to complete native outputs matching the selected startup targets
Fixed stability rank: SVD relative cutoff = max(matrix shape) × FP32 epsilon.

The solver reports rank, compatibility and coefficient change. Native FP32 writeback must satisfy the existing complete-output interface check, atol=1e-5, rtol=1e-4. Incompatibility under the declared rank policy is reported as infeasible; it is not hidden by a larger quiet weight, a relaxed threshold or development-driven tuning.

The hybrid has an accurate name: G plus a constrained upsampler. The refitted upsampler can leave G's shared hidden-map family and change its bias. Hidden-interface agreement is a diagnostic contract, not a guarantee of the final waveform. The six calibration starts and the held-out panel are evaluated separately.

Development quiet windows

The broader quiet panel. Startup is a small part of it, and the cohorts overlap.

For each anchor, retain both the residual-RMS limit and the student-output-RMS limit. Each is a squared excess that must be nonpositive. The code retains the canonical FP32 RMS calculation and then forms its squared constraint value; the notation below describes the mathematical rule.

Fresidual,i(θ) = RMS(studenti − teacheri)² − Lresidual,i² ≤ 0
Famplitude,i(θ) = RMS(studenti)² − Lamplitude,i² ≤ 0

Lresidual,i = max(√0.02 × RMS(teacheri), 1e-5)
Lamplitude,i = max(100.05 × RMS(teacheri), 1e-5)
  1. Compute the ordinary Adam proposal once.The original waveform, mel and group-feature losses remain unchanged. Use FP32 singleton batches accumulated over 12 ordinary sources, AdamW at 3e-5, betas 0.9/0.99, epsilon 1e-8 and zero weight decay. The teacher and the outer decoder stay frozen.
  2. Differentiate every current anchor constraint.Six windows × two physical limits produce all twelve rows. Gradients pass through the current student and the fixed suffix to the waveform. Keeping only each cohort's worst window can omit a window that becomes binding after the update.
  3. Project the actual Adam displacement.Find the nearest displacement in raw parameter coordinates satisfying all twelve linearized inequalities. The small FP64 solver normalizes each row and its right-hand side together, handles dependent rows and verifies the full primal and KKT conditions.
  4. Install and rescore in native FP32.The actual written parameters must pass all six waveform checks. A linear certificate alone cannot establish nonlinear feasibility.
  5. If the full trial fails, make a bounded normal correction.Recompute all twelve Jacobians at that failed trial. Solve for a minimum-norm correction with signed bounds. Try correction scales 1 and 2 from the same trial, at most two solves, and rescore every anchor.
  6. Keep the bounds and the transaction explicit.The total actual FP32 normal displacement from the original full trial must stay within 25% of the fixed original projected direction's norm. A failed trial is reused only if its worst normalized positive excess strictly improves. If bounded repair fails, use the declared extended fraction grid down to 1/1024, then zero. Hard errors restore parameters, Adam, RNG and gradients.

Execution details that matter for reproducibility
  • The ordinary objective uses waveform L1 with the unchanged mel coefficient 0.0006674012905982311 and group-feature MSE coefficient 0.009304078923434964. No quiet-loss weight is introduced.
  • The normal budget is measured after actual FP32 writeback, relative to the original projected direction. It is neither a new allowance per solve nor the sum of path lengths.
  • An accepted zero parameter displacement retains Adam's once-advanced moments and counter under the declared policy. It is reported as zero learning for that update. Hard failures roll back the full transaction.
  • A cold scripted Snake path previously gave a tiny grad/no-grad discrepancy without a pass/fail flip. Warm the actual gradient-bearing group-and-suffix execution and require exact repeat/no-grad waveform and constraint parity. Failure raises; it does not loosen acceptance.
  • Each trial starts from an authenticated teacher-derived initializer, empty Adam and fixed RNG. Paired pilots share ordinary source order and exposure. Repeated anchor evaluations are additional calibration work and are counted separately.
  • The six anchor windows are training data. The thirteen development starts never select a correction, a fraction, a rank cutoff or a fit weight.
Why all linear rows are necessary but not sufficient

A tangent step can violate a curved boundary at every positive fraction

Consider the unit disk, F(x)=‖x‖²−1≤0, at x=(1,0). A tangent displacement d=(0,a) has ∇F·d=0, yet its finite excess is a²>0. Shortening it does not make it exactly feasible in exact arithmetic. A small inward correction can preserve useful tangential progress.

A reusable procedure, not a universal compression ratio

Generalize the interfaces and evidence, not just the channel count

  1. Define the cut and its original identities.Record exactly which channels or blocks survive. Bind teacher weights, source manifests, selected-coordinate provenance and native geometry. A different support requires a freshly constructed and calibrated candidate.
  2. Trace every affected consumer.Update convolution axes, pointwise mixers, conditioning, normalization/activation parameters and residual paths consistently. If a block is removed, its entire input/output transformation and skip contract change; the present four-site channel procedure cannot simply be assumed sufficient.
  3. Fit on actual student features.After each native weight change, recapture the downstream student's real inputs. Preserve time phases, shared bias, context, partial tails and valid-sample weights. Do not splice teacher coordinates into an adapted student as a supposed repair.
  4. Separate initialization from retention.Fit on calibration sources only, then test native FP32 writeback and held-out waveform behavior. Recompute constraint Jacobians at the current model and at each failed nonlinear trial. A stale map or old gradient is not a certificate for a new candidate.
  5. Measure progress as well as feasibility.Report all calibration/development counts, continuous errors, actual update norms, zero steps, correction budgets and optimizer-state policy. Passing only because every update was rejected is not successful recovery.
  6. Requalify each independent trial.Use a fresh original-teacher-derived initialization, empty Adam and matched source exposure. Preserve failures and completed histories. The planned long trial starts again from its initializer after the short comparison, not from a selected pilot endpoint.
  7. Benchmark the exported model separately.Measure actual native inference latency, throughput, real-time factor and memory at matched hardware, duration, precision, warmup and output contracts. Verify perceptual and broad quiet behavior as well as numerical fidelity.
50% of channels is not 50% of blocks. Halving both input and output widths can reduce some dense operators' arithmetic to roughly one quarter, while other operators, fixed stages and runtime overhead scale differently. Removing half the blocks changes depth and function. Neither description implies a 10× end-to-end speedup. Only a matched benchmark of the exported decoder can support that claim.

Future width cuts: analytic convolution cost

The proposed shorter campaign measures CPU gains before substantial recovery. Its width steps are stage 2 from 384 to 256, then stage 3 from 256 to 128 if the first cut is useful, with a separate quality review at each step. No new cut has started. The final 256/128 support is 50% of each stage's original width, not removal of 50% of its layers. All nine residual units and their temporal support remain in this width-only plan.

For comparison, deleting one residual unit from each of stages 2–4 at original widths saves only 10.35% of the original convolution MAC count and changes temporal support. The width reductions above preserve that support. The most transferable idea is to treat pruning as a change to interfaces, then restore useful behavior using the new model's own features and enforce important physical bounds on actual finite updates. The particular support, six anchors and numerical settings are evidence for this experiment, not universal defaults.
