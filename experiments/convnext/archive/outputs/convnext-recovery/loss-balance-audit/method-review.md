# Loss-balance method audit

Read-only review of saved results, local training code and primary literature. No model forward pass, training, benchmark or implementation change was performed.

## The important distinction

The 1,016-fold quiet/active gradient imbalance belongs to the **isolated repair pilots**, whose waveform objective uses separately normalized regional MSE. It is not evidence that the original 8,890-step student used that objective. The actual RecipeV2 engine uses raw sample-pooled waveform L1, multiresolution mel, an EMA output-gradient balancer, and the scheduled adversarial/feature-matching branches. The latest short pilots bypassed those GAN/FM updates. [Pilot objective](/Users/venky/Documents/Codex/2026-09-07/https-arxiv-org-html-2402-10533v2/work/convnext-recovery/architecture-experiments/run_teacher_refinements_v2.py:144), [original reconstruction](/Users/venky/Documents/Codex/2026-09-07/https-arxiv-org-html-2402-10533v2/work/fast-audiovae/experiments/convnext/audiovae_student/reconstruction_v2.py:63), [RecipeV2 training](/Users/venky/Documents/Codex/2026-09-07/https-arxiv-org-html-2402-10533v2/work/fast-audiovae/experiments/convnext/audiovae_student/recipe_v2.py:162).

Thus the next correction should first restore a faithful reconstruction objective for the diagnostic comparison. It should not introduce a new Huber threshold or another inverse-error normalization by default. Raw L1 already exists and is the minimal choice.

## What the measurements actually establish

| Objective | Quiet contribution and observed limitation |
|---|---|
| Pilot regional MSE divided by initial regional error | Quiet output-gradient norm is approximately 1,016 times active on the fixed initial probe. Wave/mel parameter-gradient cosine is −0.488 initially and −0.536 finally. |
| Pilot global waveform MSE | Quiet contributes 0.004389% of calibration waveform-gradient energy. Wave/mel output norms are similar, but waveform parameter norms are 15.47 times mel initially and 11.60 times finally. |
| Existing raw sample-pooled L1 | For nonzero errors, every valid sample has derivative magnitude `1/N`. With the full FIT sample counts, the analytical quiet share is 13.30794% of output-gradient energy, and quiet/active norm ratio is 0.391801. This is a derivation, not a new measured training result. |

L1 avoids both amplitude-driven MSE extremes before balancing. It does not guarantee silence convergence: its derivative does not shrink continuously as an error approaches zero, so finite optimizer steps can still oscillate. Nor does it enforce a hard output-amplitude bound. Keep quiet samples at the same fixed per-sample weight as speech initially. A separate quiet multiplier requires evidence and a declared fixed policy, not automatic division by tiny residual error.

In the pooled-MSE arm, the weighted mel gradient has inner product `-2.04048e-6` initially and `-1.03241e-6` finally with the combined parameter gradient. An infinitesimal plain-SGD step would therefore worsen mel on that probe, consistent with measured MAE improvement and mel regression. Conversely, the earlier regional-MSE probe had a negative cosine but a combined descent direction for both objectives. A negative cosine alone is insufficient to declare destructive optimization. ## What the literature supports

| Method | Useful principle | Limit for this decoder |
|---|---|---|
| EnCodec Balancer | Normalize individual loss gradients at reconstructed audio using running norms and explicit desired fractions. | Does not promise equal contributions after the decoder Jacobian or optimizer. We already implement this principle. |
| GradNorm | Measure weighted gradients on shared parameters and adjust weights using relative training rates. | Adds adaptive weighting and an asymmetry parameter; equal parameter norms still do not imply equal AdamW effects. |
| PCGrad | Project conflicting task gradients to reduce interference. | Changes directions and introduces projection ordering. Its empirical use with Adam does not establish per-example, per-step non-regression here. |
| CAGrad | Seek a direction near the average gradient that improves the worst local task direction. | The published stationary-point result assumes its specified gradient-descent setting, smoothness and step constraints. It is not a guarantee for our stochastic AdamW/GAN dynamics. |

These are primary references, not evidence that any method has already improved this model: [EnCodec paper, §3.4](https://arxiv.org/html/2210.13438#S3.SS4), [official Balancer implementation](https://github.com/facebookresearch/encodec/blob/main/encodec/balancer.py), [GradNorm](https://proceedings.mlr.press/v80/chen18a.html), [PCGrad](https://arxiv.org/html/2001.06782), [CAGrad](https://proceedings.neurips.cc/paper/2021/file/9d27fdf2477ffbff837d73ef7ae23db9-Paper.pdf).

The existing balancer's documentation correctly says its shares apply before summing audio gradients, not to parameter-update norms. Merely replacing that code with “equal shared-parameter norms” would make a different promise, not solve the optimizer issue. [Local balancer](/Users/venky/Documents/Codex/2026-09-07/https-arxiv-org-html-2402-10533v2/work/fast-audiovae/experiments/convnext/audiovae_student/gradient_balancer.py:1).

## Minimal proposal before another training decision

1. **Use the existing teacher L1 and mel definitions in the next bounded head comparison.** Retain exact cached latents, valid-sample/frame pooling, frozen prefix and normalization, the current head scope and fresh AdamW at `1e-6`. Keep quiet sample weight one. The original full RecipeV2 EMA balancer remains unchanged. For this isolated runner, one fixed mel coefficient can start from the median of per-training-batch `||g_L1|| / ||g_mel||` over the same trainable head. This is a robust scalar calibration heuristic, not GradNorm or a guarantee. Log and exclude zero-gradient ratios rather than manufacturing a large coefficient with epsilon; require a nondegenerate calibration panel. No numerical coefficient is justified before measurement. This repairs the diagnostic contract without claiming a solution to the original plateau.
2. **Check actual optimizer movement before selecting a new balancing method.** For a small training-only calibration panel, retain each branch gradient `g_i` and measure the candidate AdamW displacement `delta = theta_after - theta_before`. Log `g_i · delta` and the actual same-panel loss change, including quiet and peak diagnostics. Negative dot products predict local improvement; positive values flag conflict. Compare predicted and actual changes to distinguish direction conflicts from finite-step/curvature effects. Include clipping, momentum, second moments, epsilon and decay exactly; restore every trial's weights, optimizer state, RNG and statistics. This is a proposed calibration audit, not work run here.
3. **Adjust only if those measurements justify it.** Shared-parameter norms suggest the initial scale but cannot be the acceptance criterion. Freeze the selected coefficient for the bounded comparison; check actual updates early and late because first-step Adam does not yet have representative moments. The displacement check must use all trainable parameters; auxiliary comparisons additionally report their genuinely shared block. If training directions improve but held-out regions regress, more balancing is not the established fix. Do not require every noisy example to improve every step or tune weights on held-out failures.
4. **Keep the full recipe separate from the head diagnostic.** RecipeV2's GAN/FM branches already exist. A later full continuation must explicitly restore their state and schedule, log their real contributions and avoid reinstating a near-perfect-correlation entry requirement. Their absence from these small reconstruction pilots is not evidence that they were absent from the original training. They add training cost, not decoder inference operations.

AdamW's moment-dependent coordinate scaling explains why Euclidean gradient-norm ratios and learning-rate changes alone cannot settle the question. The actual update is not simply `-lr * summed_gradient`. [Adam paper](https://arxiv.org/abs/1412.6980), [official AdamW implementation](https://github.com/pytorch/pytorch/blob/main/torch/optim/adamw.py).

## Keep objectives and acceptance criteria distinct

Average L1/mel minimizes average error. It does not guarantee the present per-source 1% spectral limits, a 10% quiet reduction, or zero new peak regressions. Current automatic spectral gates apply only to whole-source results; quiet/active/transition regions are diagnostics. [Selection checks](/Users/venky/Documents/Codex/2026-09-07/https-arxiv-org-html-2402-10533v2/work/convnext-recovery/architecture-experiments/run_teacher_refinements_v2.py:152), [spectral gate scope](/Users/venky/Documents/Codex/2026-09-07/https-arxiv-org-html-2402-10533v2/work/convnext-recovery/architecture-experiments/run_spectral_heads.py:187).

Retain those held-out guards and compare both the retained candidate and original 8,890 checkpoint. Also retain frame-support counts and the existing expressive coverage limitations. A teacher waveform target encourages bounded output but cannot hard-bound an unconstrained linear head. A lightweight vocoder sounding good under its own conditioning is not evidence that it satisfies our exact AudioVAE2 latent, silence, peak and waveform-reconstruction contract. This leaves architecture-specific issues open, without treating failed short pilots as proof that new layers are required.

Recommendation: first return the diagnostic to the existing L1 recipe and make update-level evidence trustworthy. Keep GradNorm/PCGrad/CAGrad as named alternatives, not a stack of new mechanisms. No method in this audit is authorized or claimed to guarantee teacher parity, and no additional tests or training were started.

## Narrow audit of silence gradients and reduction semantics

The following are confirmed implementation properties, not proven causes of current failures:

- **The log-mel branch has an explicit floor.** The default epsilon is `1e-5` in mel-magnitude units, not PCM amplitude or a directly equivalent dBFS cutoff. At predicted mel magnitude below that floor, `log(clamp_min(...))` gives no gradient through that predicted bin. If both teacher and prediction lie below it, their log loss is zero even if magnitudes differ. The linear-mel term remains available, so this is not a dead zone for the entire reconstruction objective. Near the floor from above, the log derivative can be large. We have not measured how many current silence bins occupy either regime. [Configuration](/Users/venky/Documents/Codex/2026-09-07/https-arxiv-org-html-2402-10533v2/work/fast-audiovae/experiments/convnext/audiovae_student/reconstruction_v2.py:24), [both spectral terms](/Users/venky/Documents/Codex/2026-09-07/https-arxiv-org-html-2402-10533v2/work/fast-audiovae/experiments/convnext/audiovae_student/reconstruction_v2.py:111).
- **Magnitude spectra have the expected phase and exact-zero limits.** Reconstruction uses `abs(STFT)` before mel projection. This cannot uniquely identify waveform phase. PyTorch's absolute-value derivative uses the complex sign, which is zero at an exactly zero complex input. Therefore an exactly zero predicted STFT coefficient has no local derivative through its magnitude, even when the target differs. The direct waveform L1 term still has a nonzero derivative wherever the predicted waveform differs from its teacher. Nonzero quiet residuals are not evidence of exactly zero STFT bins. [Magnitude path](/Users/venky/Documents/Codex/2026-09-07/https-arxiv-org-html-2402-10533v2/work/fast-audiovae/experiments/convnext/audiovae_student/reconstruction_v2.py:105), [PyTorch derivative definition](https://github.com/pytorch/pytorch/blob/main/tools/autograd/derivatives.yaml#L220).
- **Some boundary samples intentionally lack spectral supervision.** `center=False` admits only complete STFT windows; periodic Hann starts at zero, and an incomplete final hop is omitted. The pilot also excludes an entire scored span shorter than the largest FFT from every spectral scale, while retaining waveform loss. This is explicit accounting, not a silently dropped waveform chunk. Saved latest FIT/selection accounting reports zero such wholly excluded short spans; partial final-hop spectral coverage is a separate property. These boundary limits cannot by themselves explain a residual persisting deep inside long silence. [STFT call](/Users/venky/Documents/Codex/2026-09-07/https-arxiv-org-html-2402-10533v2/work/fast-audiovae/experiments/convnext/audiovae_student/reconstruction_v2.py:106), [pilot exclusions](/Users/venky/Documents/Codex/2026-09-07/https-arxiv-org-html-2402-10533v2/work/convnext-recovery/architecture-experiments/run_spectral_heads.py:96).
- **Sample-pooled losses and per-example norm estimates are different reductions.** Reconstruction sums valid sample errors and spectral elements before division. The full-training balancer instead averages per-example L2 gradient norms after masking context/padding, then applies one scalar per loss to every example. For raw L1 its norm statistic is proportional to `mean(sqrt(N_i))/sum(N_i)`, not the global batch gradient norm. Consequently the estimated branch scale depends on crop-length composition and batching. It does not restore equal per-example waveform weighting or inflate each quiet clip separately, because the resulting scalar is shared across the batch. This deliberate EnCodec-style convention is already documented. The saved frozen pilot coefficients use yet another explicit convention, summed gradient energies over four batches, so they should not be described as exact EMA-balancer replay. [Loss aggregation](/Users/venky/Documents/Codex/2026-09-07/https-arxiv-org-html-2402-10533v2/work/fast-audiovae/experiments/convnext/audiovae_student/reconstruction_v2.py:149), [balancer norm and scalar application](/Users/venky/Documents/Codex/2026-09-07/https-arxiv-org-html-2402-10533v2/work/fast-audiovae/experiments/convnext/audiovae_student/gradient_balancer.py:208).

No additional confirmed bug emerged from this narrow review. Do not change the spectral floor, STFT magnitude path or norm reduction based on these theoretical limits alone. If later diagnostic evidence is needed, log floor occupancy, exact-zero coefficients and realized branch scales by region on training data, rather than presuming that low RMS implies a clamped spectral gradient.
