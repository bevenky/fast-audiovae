# v0.5.0

The Apple INT8 streaming release is now version 0.5.0. This is the same validated implementation as 0.4.2, with unchanged runtime code, CPU kernels, GPU support and quality results.

Compatible Apple CPUs automatically select INT8 for one-thread streaming. Multithreaded and batch modes retain FP32. CPU is the default; GPU dependencies and execution remain optional.

```sh
python -m pip install fast-audiovae==0.5.0 --find-links https://github.com/bevenky/fast-audiovae/releases/expanded_assets/v0.5.0
```

Apple ARM, Linux x86 and portable wheels, a source archive and SHA256SUMS are included. [Apple quality and timing](https://github.com/bevenky/fast-audiovae/blob/v0.5.0/docs/apple-int8.md).

The inherited qualification covers 79 recordings at both 40 and 80 ms, 563 tests plus 1,963 subtests, and the isolated installed-wheel checks. Version-only packaging is checked separately for unchanged runtime and native bytes.
