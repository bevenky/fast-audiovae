# v0.4.2

Apple CPUs with verified SME and SME2 now automatically use the validated INT8 projections for one-thread causal streaming. Only two projections change. Multithreaded streaming, batch, Linux CPU kernels and optional Apple GPU execution retain their existing paths.

The native Apple wheel includes the self-contained KleidiAI implementation. Installation needs no compiler. CPU-only installation still excludes PyTorch; the `gpu` extra remains optional.

The 79-recording confirmation found 25.4% less decoding time at 40 ms and 13.1% at 80 ms. Fresh quality scoring on 60 multilingual speech recordings stayed very close to the previous default. These timings are from one matched validation session, not a new Mimi comparison.

[Apple results and scope](https://github.com/bevenky/fast-audiovae/blob/v0.4.2/docs/apple-int8.md).

```sh
python -m pip install fast-audiovae==0.4.2 --find-links https://github.com/bevenky/fast-audiovae/releases/expanded_assets/v0.4.2
```

Assets include Apple ARM and Linux x86 native wheels, a portable wheel, a source archive and SHA256SUMS. Wheels are published here on GitHub Releases.

Validation: 563 tests and 1,963 subtests passed. All 158 shipping waveforms across 79 recordings matched the qualified candidate exactly. The isolated installed-wheel check passed all 26 waveform checks, including retained multithreaded and batch paths. [Validation record](v0.4.2-validation.json).
